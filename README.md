# Eye Go Optical website

Static multi-page website published from GitHub Pages. The deployment workflow publishes the HTML, CSS, JavaScript, robots.txt, and sitemap.xml from the repository root when changes are pushed to `main`.

## Pages

Home, About, Services, Accessibility, School Screenings, Eye Go International, Eyewear & Brands, Insurance, Financing, Book Appointment, Contact, and Location.

## Integrations

- Cherry financing and Setmore scheduling retain the owner-provided embeds.
- The contact form opens the visitor’s email app with a message addressed to info@eyegooptical.com. The visitor must review and send the message; direct server-side delivery requires a separate host that supports server functions.
- No public invoice or review feature is included.
